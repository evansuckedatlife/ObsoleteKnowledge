## summary

**Genetic code** is the universal dictionary that translates nucleotide sequences in DNA and RNA into protein sequences, using three-nucleotide codons to specify amino acids or stop signals. Cracked in the 1960s by *Nirenberg*, *Khorana*, and others, it revealed that the same sixty-four codon rules apply across nearly all life, from bacteria to humans. This near-universality points to a common evolutionary origin and makes molecular biology quantitative.

## you gotta know

- Based on triplet codons: each three-nucleotide mRNA sequence specifies one amino acid or a stop signal (UAA, UAG, UGA).
- Sixty-four codons code for 20 standard amino acids plus stop signals; redundancy (degeneracy) means multiple codons specify the same amino acid.
- Wobble position: third codon position allows non-standard base pairing (e.g., G-U); one tRNA's anticodon can decode multiple codons, reducing required tRNA types from 64 to ~40–60.
- Nearly universal across domains; rare variant codes exist in mitochondria (UGA codes for tryptophan, not stop), some Candida species, and a few bacterial lineages.
- AUG initiates translation (codes for N-formyl-methionine in prokaryotes, methionine in eukaryotes); three stop codons terminate translation.
- Decoded during translation by transfer RNAs (tRNAs), each with an anticodon (mRNA-binding) and a cognate amino acid attached by aminoacyl-tRNA synthetase.
- Non-overlapping and non-punctuated: ribosome reads mRNA in a fixed reading frame, three nucleotides per codon, without gaps or overlaps.
- Determined empirically by *Nirenberg* (synthetic RNA templates synthesizing polypeptides without cells), *Khorana* (sequential trinucleotide decoding), and others in the 1960s.
- Implications: genetic code is degenerate (synonymous codons), which buffers mutations; third-position substitutions often don't change amino acids (silent mutations).
- Near-universality suggests common evolutionary origin of all known life; variant codes evolved separately in mitochondria and isolated lineages after billions of years of divergence.
- Redundancy in the genetic code buffers mutations; most nucleotide changes don't alter the encoded amino acid (silent mutations), protecting protein function.
