## summary

**Codons** are three-nucleotide sequences on messenger RNA (mRNA) that specify which amino acid should be added during protein synthesis, or signal the start or end of translation. They form the reading frame of the [[genetic-code]], the universal cipher translating nucleic acid information into protein sequences. Nearly all organisms use the same codon table, making it one of biology's most fundamental languages.

## you gotta know

- Each codon consists of three ribonucleotides: adenine, guanine, cytosine, or uracil, giving 64 possible combinations (4³).
- 61 codons code for the 20 standard amino acids; the remaining three are stop signals (UAA, UAG, UGA).
- The genetic code is degenerate — multiple codons encode the same amino acid, providing redundancy against mutations.
- [[start-codon]] AUG (codes for methionine) initiates translation; ribosomal scanning begins at the 5' cap of mRNA and finds the first AUG.
- [[transfer-rna]] (tRNA) molecules carry anticodons that pair with mRNA codons via Watson-Crick base pairing.
- The reading frame is defined by where translation starts — shifting by one or two nucleotides changes all downstream codons, often producing a non-functional protein.

## connections

- [[mrna]] — the RNA strand containing codons.
- [[trna]] — molecules whose anticodons recognize codons.
- [[protein-synthesis]] — the process where codons are read.
- [[genetic-code]] — the table mapping codons to amino acids.
- [[amino-acids]] — the molecules added to the growing protein chain.
- [[ribosome]] — the cellular machine that reads codons.
