## summary

**Ethereum** is a decentralised, open-source blockchain network featuring smart contract functionality, conceived in late 2013 by programmer *Vitalik Buterin*. Unlike purely transactional ledgers, it provides a Turing-complete virtual machine designed to execute arbitrary code across a globally distributed peer-to-peer network. Its native cryptocurrency, **Ether**, fuels computations and secures decentralized finance platforms, digital tokens, and web applications worldwide.

## you gotta know

- Proposed in 2013 by *Vitalik Buterin* in a seminal white paper titled "A Next-Generation Smart Contract and Decentralized Application Platform" and launched in July 2015.
- Powered by the *Ethereum Virtual Machine* (EVM), a sandboxed execution environment that allows untrusted code to run predictably across all participating nodes.
- Introduces deterministic "smart contracts," self-executing agreements whose terms are directly written into immutable lines of distributed code.
- Uses its native cryptocurrency, **Ether** (ETH), to compensate network validators via "gas" fees charged proportionally to the computational complexity of transactions.
- Underwent a historic consensus overhaul in September 2022 known as "The Merge," transitioning entirely from energy-intensive Proof-of-Work to Proof-of-Stake.
- Serves as the foundational base layer for Decentralized Finance (DeFi) protocols and token standards like ERC-20 for fungible assets and ERC-721 for non-fungible tokens.
- Suffered a contentious 2016 exploit of *The DAO*, prompting an ideological hard fork that preserved the current ledger while leaving the unaltered chain behind as *Ethereum Classic*.
