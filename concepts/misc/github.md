## summary

**GitHub** is a cloud-based software development forge and social coding platform built upon the distributed version control architecture *Git*, founded in 2008 by *Chris Wanstrath*, *P. J. Hyett*, *Tom Preston-Werner*, and *Scott Chacon*. Acquired by *Microsoft* in 2018 for seven and a half billion dollars in corporate stock, it functions as the central global infrastructure for collaborative open-source programming, issue triage, and continuous integration. Recognized visually by its hybrid feline-cephalopod mascot *Mona the Octocat*, the service transformed modern software craftsmanship by democratizing code contributions through web-based forks, distributed branching, and peer pull requests.

## you gotta know

- Built on top of *Git*, the decentralized version control engine originally created in 2005 by *Linus Torvalds* to coordinate the global engineering of the *Linux* kernel.
- Pioneered the modern social coding paradigm by introducing the *pull request*, transforming routine patch submissions into public, line-by-line interactive discussions and continuous code reviews.
- Acquired by longtime computing titan *Microsoft* in October 2018, operating under independent leadership while integrating deeply with enterprise infrastructure and cloud deployments.
- Employs *Mona the Octocat*, an anthropomorphic character featuring five octopus tentacles and a domestic cat face, designed by graphic artist *Simon Oxley*.
- Hosts millions of public repositories, including dominant foundational open-source technologies such as *Linux*, *CPython*, *Kubernetes*, *React*, and the *Chromium* browser engine.
- Expanded beyond code storage into complete developer automation through *GitHub Actions* for automated testing and *GitHub Copilot*, a pioneering AI pair programmer built with *OpenAI*.
- Preserved historical source code for future civilizations through the *GitHub Arctic Code Vault*, storing open repositories on durable film deep inside an abandoned Svalbard coal mine.
